# Content examples

Runnable examples for the articles and videos on [sndv.xyz](https://sndv.xyz/).

[**Intelligence liquidity**](python/intelligence-liquidity/README.md) follows a liquid neural network from the first office benchmark through training and rollback, a failed transfer to a different room, and a separate reward-based heating experiment.

Example code is available under the [MIT License](LICENSE). Reused dataset
extracts keep the licenses credited in each example.

The [adaptive liquid board](python/intelligence-liquidity/adaptive-liquid-board/README.md) extends the verified network with guarded splits, learned expert hierarchies, delta memory and same-data comparisons.
