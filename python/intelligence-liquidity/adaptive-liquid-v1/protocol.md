Use the benchmark's exact three seeds (41, 42, 43), three occupancy budgets (25%, 50%, 100%), fitting window membership, chronological validation, training-only normalization, Adam settings and validation early stopping. Report individual seeds and descriptive mean and range. Overlapping windows, common holdout rows and repeated training seeds preclude treating these scores as independent observations.

## Architecture and comparisons

The three serial conductance stages share architecture but have separate parameters and separate liquid critics. Each critic sees its stage's proposal, state, delta output, elapsed time and upstream evidence. Conductance uses the same semi-implicit update as the measured benchmark. The [Kimi Delta Attention paper](https://arxiv.org/abs/2510.26692) motivates the reference recurrence. It decays key channels independently, computes the write residual against the decayed pre-write state, then reads with a learned output gate. The small reference recurrence uses a single memory head.

Stage critics learn fitting-only binary targets from each stage's classification error or standardized outcome RMSE. An additional negative view shifts critic inputs computed from available history. Detach all critic inputs and all evidence passed back into the predictors. Score losses update critic weights. Supervised losses train the predictors and corrective transforms. Every fourth fitting minibatch exercises stage-two feedback when enabled. At inference a nonnegative critic logit passes. Stage one has no preceding stage to revisit. Stage two and three each get at most one replay and can abstain after a failed replay. Any stage abstention vetoes acceptance but ordinary occupancy logits are still reported for matched all-row comparisons.

Compare current row, GRU, library LTC, custom LTC, soft attention and soft attention with auxiliary targets on occupancy. Compare bucket mean, custom LTC and soft attention on heating. Each gains full adaptive, no feedback (no replay), delta only (no corrective replay or interstage critic evidence), hard only (no learned-score routing or reward), and no delta (zeroed memory channels). Identical tensor widths permit parameter-count comparison.

Hard stage checks enforce finite inputs, finite proposals and strictly positive finite elapsed times. Heating also requires a binary action, finite physical predictions and at least eight fitting windows supporting each action in the existing prior-trend/temperature bucket. These checks establish numeric validity and sample availability. They cannot establish physical accuracy, causal overlap or safety. Among passing heating candidates rank by predicted negative thermal kWh minus twice degree-hours, plus 0.1 times mean critic probability where enabled. Log those components separately. Heating tests compare logged-action predictions only. Both actions are evaluated from causal observations, and the unchosen outcome is unobserved.

## Holdout handling

UCI and ZEB publisher data and Danish apartments use the immutable archive checks and existing loader. These datasets have been explored. Graz v2 uses the archive for [Zenodo record 11573783](https://zenodo.org/records/11573783). Join raw image labels and raw sensors by UTC after interpreting the label wall clocks in Europe/Vienna. Drop missing/invalid/ambiguous labels and missing readings with no interpolation. Use only raw temperature, humidity and CO₂. Require the exact eight five-minute timestamps from 45 to 10 minutes before each label, plus a sensor timestamp at the label for explicit alignment; its values and the preceding five-minute row are excluded. This embargo keeps the last sensor bin before the label even under a start-of-bin convention. Use the intermediate image-label file to cross-check time alignment, never as a feature or a fallback. Cross-site differences in cadence, sensors, building use and image labels constrain comparisons.

Freeze code and criteria before evaluating Graz. A parser-only correction must retain the original freeze receipt, document what changed and when, and leave model, training and selection unchanged. Report actual replay and acceptance counts, including zero values. The new experiment cannot establish an efficiency advantage if matched holdout accuracy or logged-action error fails to improve, or if accepted-only performance depends on very low coverage.
